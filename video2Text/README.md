# 视频转文案自动化工具 (Video to Text & AI Polishing)

## 部署说明

### 1. 已完成项
- **运行环境**: Python 3.10 隔离环境 (via micromamba) 已搭建。
- **ASR 模型**: 
    - `Paraformer-zh` 识别模型已下载完成 (233MB)。
    - `Punc_ct-transformer` 标点模型已下载完成 (965MB)。
- **核心逻辑**: 音频提取 (FFmpeg)、离线 ASR 识别、LLM (Qwen) 对接逻辑已编写。
- **前端界面**: 基于 Vue 3 + Tailwind 的 Web UI 已就绪。

### 2. 快速启动指令
1. **准备模型**:
   将 ASR 模型放到以下目录：
   - `backend/models/paraformer-offline-zh`
   - `backend/models/punc_ct-transformer_cn-en`

   模型文件体积较大，不纳入 git。

2. **安装依赖**:
   ```bash
   pip install -r requirements.txt
   ```

3. **配置环境变量**:
   - `VIDEO_ROOT`: 视频目录，默认 `./videos`
   - `OUTPUT_ROOT`: 输出目录，默认 `./backend/output`
   - `TASK_DB_PATH`: 任务数据库路径，默认 `./backend/tasks.db`
   - `QWEN_API_KEY`: 阿里云 DashScope API Key，仅在启用文案/标题/封面提示词生成时需要

4. **运行服务**:
   ```bash
   cd video2Text
   bash start.sh
   ```

5. **访问界面**:
   打开浏览器访问：`http://服务器IP:8000/frontend/index.html`。

### 3. 文件结构
- `backend/`: 
    - `main.py`: FastAPI 服务及核心调度。
    - `asr.py`: Sherpa-Onnx 识别封装。
    - `llm.py`: Qwen 大模型对接及提示词模板。
    - `models/`: ASR 与标点模型存放地（git 忽略）。
    - `output/`: 转换结果存放地（每个视频一个文件夹，git 忽略）。
- `frontend/`: 
    - `index.html`: Web 交互界面。
- `videos/`: 待处理视频存放地（git 忽略，可通过 `VIDEO_ROOT` 配置）。
- `start.sh`: 一键启动脚本。

### 4. 当前默认行为
- 默认只执行“提取音频 + ASR 转写”。
- 标题建议、封面提示词、平台文案都改为前端可选项，且默认关闭。

# Windows-Reminder

Windows-Reminder 是一款专为 Windows 用户设计的轻量级悬浮窗待办提醒工具。它能将您的任务以半透明、置顶的方式直接显示在屏幕桌面上，帮助您时刻关注重要事项。

## 核心功能

- **半透明置顶悬浮窗**：任务时刻可见，且不干扰其他程序操作（支持鼠标穿透）。
- **可调节透明度**：通过系统托盘菜单，支持多种透明度级别（20%, 50%, 80%, 100%）。
- **布局切换**：支持竖向任务列表，也支持横向排列（如：任务A、任务B、任务C）。
- **文字颜色切换**：支持白色和黑色任务字体，适配深色或浅色背景。
- **位置自定义与拖拽**：按住 `Ctrl + Alt` 键即可开启拖拽模式，自由调整悬浮窗位置，且位置会被自动保存。
- **番茄钟功能**：集成了 25 分钟番茄钟计时器，支持开始、停止和重置。
- **任务管理界面**：便捷的图形化操作界面，用于添加、编辑和删除待办事项。
- **系统托盘集成**：支持托盘图标管理，方便隐藏/显示悬浮窗及退出程序。

## 安装与运行

### 环境要求

- Python 3.9+
- Windows 操作系统

### 步骤

1. **克隆项目或下载源码**：
   ```bash
   git clone <project-url>
   cd Windows-Reminder
   ```

2. **创建并激活虚拟环境（推荐）**：
   ```bash
   python -m venv venv
   .\venv\Scripts\activate
   ```

3. **安装依赖**：
   ```bash
   pip install -r requirements.txt
   ```

4. **运行程序**：
   ```bash
   python -m src.main
   ```

## 快捷键说明

- **`Ctrl + Shift + R`**：切换悬浮窗的显示与隐藏。
- **`Ctrl + Alt` (长按)**：开启位置调整模式。此时悬浮窗会显示边框，您可以使用鼠标左键拖动。

## 托盘菜单

- **Manage Tasks...**：打开任务管理窗口。
- **Opacity**：调整悬浮窗透明度。
- **Layout**：在 `Vertical`（竖向）和 `Horizontal`（横向）之间切换。
- **Text Color**：在 `White`（白色）和 `Black`（黑色）字体之间切换。
- **Pomodoro**：开始、停止或重置番茄钟。

## 项目结构

- `src/`：源代码目录。
  - `main.py`：程序入口，管理应用逻辑。
  - `overlay.py`：悬浮窗 UI 实现。
  - `editor.py`：任务管理器 UI。
  - `models.py`：数据模型定义。
  - `services/`：后端逻辑服务（存储、热键等）。
- `assets/`：静态资源（图标等）。
- `requirements.txt`：项目依赖库列表。

## 数据存储

用户的任务数据和设置（如坐标位置、透明度、布局方向、文字颜色）存储在系统 `%APPDATA%\Windows-Reminder\items.json` 中，确保跨版本升级或重启后数据不丢失。
